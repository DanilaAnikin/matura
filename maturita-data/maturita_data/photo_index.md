## 1000057490.jpg — Pevné látky (krystaly Si)
Výpočet hustoty částic v krystalu křemíku.
- ρ_Si = 2330 kg/m³
- Ar_Si = 28,1 (relativní atomová hmotnost)
- Plošně centrovaná mřížka — 4 atomy na buňku
- Výsledek: N = 5·10²⁰ /m³, mřížková konstanta a = 4,3·10⁻¹⁰ m
**Téma: T10 — Pevné látky / krystalová struktura**

## 1000057491.jpg — Stejnosměrný proud v PL (úloha 15)
a) Sériové vs. paralelní zapojení odporů, určení vnitřního odporu Ri = 1 Ω, Ue = 6 V
b) Závislost odporu na teplotě: R₂ − R₁ = α·R₁·ΔT, R₂ = R₁(1+αΔT)
**Téma: T15 — Stejnosměrný proud v pevných látkách**

## 1000057492.jpg — Elektrický proud, polovodiče (teorie)
- I = dQ/dt, [I] = A, jednotkový náboj e = 1,602·10⁻¹⁹ C
- Vodič: ↑T → ↑R; polovodič: ↑T → ↓R
- G = 1/R [S]
- W = U·I·t, P = W/t = U·I, [P] = W
- Vlastní polovodič (e⁻ + d⁺), příměsové polovodiče typu N (donory) a typu P (akceptory)
**Téma: T3 — Elektrický proud v polovodičích**

## 1000057493.jpg — Přechod PN, tranzistory
- PN přechod: P (+) ─── N (−), polarizace propustný/závěrný směr
- VA charakteristika diody
- Bipolární tranzistory: NPN, PNP s vyznačenými oblastmi E, B, C
- Unipolární (řízený polem) tranzistor — N-N kanál
**Téma: T3 — Polovodiče (pokračování)**

## 1000057494.jpg — Proud v kapalinách a plynech
- Elektrolyt: anoda (+), katoda (−), elektrolýza, disociace
- Faradayovy zákony elektrolýzy
- Plyny: ionizace, samostatný/nesamostatný výboj, jiskra, oblouk, koróna
- Voltampérová charakteristika výboje s nasyceným proudem I_N
**Téma: T3 — Proud v kapalinách a plynech**

## 1000057495.jpg — Elektrostatické pole + Vodiče
- Coulombův zákon F_e = k·Q₁Q₂/r² · r⃗/r, k = 1/(4πε)
- Intenzita E⃗ = F⃗_e/Q₂, potenciál φ_A = W_e/Q₂
- E⃗ = −grad φ = −(∂φ/∂x, ∂φ/∂y, ∂φ/∂z)
- Vodič: R = ρ·l/S, [R] = Ω, G = 1/R
- I = dQ/dt
**Téma: T6 — Elektrostatické pole / Elektrický proud — teorie**

## 1000057496.jpg — Kirchhoffovy zákony, sériové/paralelní řazení rezistorů
- U = R·I (Ohmův zákon), tg α = R v grafu U(I)
- Sériově: R = R₁ + R₂, U = U₁ + U₂
- Paralelně: G = G₁ + G₂, tj. 1/R = 1/R₁ + 1/R₂, I = I₁ + I₂
**Téma: T15 — Stejnosměrný proud — Ohmův zákon, řazení rezistorů**

## 1000057497.jpg — Měření, výkon
- Měření R: voltmetr a ampérmetr (zapojení), R_MIN, R_MAX
- Galvanometr (princip)
- W = U·I·t, P = U·I [W], dQ·U = W
- Spotřeba 1 kWh
**Téma: T15 — Práce a výkon stejnosměrného proudu**

## 1000057498.jpg — Elektrický zdroj, Kirchhoffovy zákony
- Vnější obvod: zdroj + spotřebič
- U_e = elektromotorické napětí, vnitřní odpor R_i
- U_e = R_i·I + R·I, svorkové napětí U_e − R_i·I = R·I
- 1. KZ: I₁ + I₂ = I₃ (uzel)
- 2. KZ: pro každou smyčku Σ U = 0
**Téma: T4 — Elektrický zdroj a obvod**

## 1000057499.jpg — Elektrostatika
- E⃗ = F⃗/Q, F⃗ = Q·E⃗, [E] = N·C⁻¹
- Elementární náboj e = 1,602·10⁻¹⁹ C, Q = z·e
- φ = W/Q, [φ] = J·C⁻¹ = N·m·C⁻¹, [U] = V
- Coulombův zákon F⃗_e = k·Q₁Q₂/r² · r⃗/r, k = 1/(4πε), permitivita
**Téma: T6 — Elektrostatické pole**

## 1000057500.jpg — Polarizace, Faradayova klec
- Vodič s volným nábojem vs. izolant (dielektrikum)
- Elektrostatická indukce, polarizace dielektrika
- Polární vs. nepolární molekuly
- |E|/|E_n| = ε_r, ε = ε₀·ε_r, ε₀ = 8,85·10⁻¹² F·m⁻¹
- Faradayova klec
**Téma: T6 — Elektrostatické pole — vodiče a izolanty**

## 1000057501.jpg — Kondenzátor
- Q = C·U, C = ε·S/d
- Spojení paralelně: C = C₁ + C₂
- Spojení sériově: 1/C = 1/C₁ + 1/C₂
**Téma: T6 — Kapacita / kondenzátor**

## 1000057502.jpg — Lom světla, Fermatův princip
- Snellův zákon: sin α / sin β = n₁/n₂ = v₂/v₁
- Δ ACD ≅ Δ CAB (důkaz Fermatova principu)
**Téma: T7 — Geometrická optika / lom**

## 1000057503.jpg — Vlnová optika
- Bílé světlo, vlnové délky 360–760 nm
- Foton: E = hf, dualistický charakter
- Huygensův princip, body ve fázi, vlnoplocha
- Odraz: α = α', sin α / sin β = n₁/n₂ = v₂/v₁
- Mezní úhel α_m: sin α_m = n₁/n₂
- Ohyb na štěrbině
**Téma: T24 — Vlnová optika / T5 — Elmag. vlnění**

## 1000057504.jpg — Geometrická optika (zrcadla, čočky)
- Zrcadla: rovinné, kulové duté/vypuklé
- Předmět (+), obraz, ohnisková vzdálenost f = r/2
- Zobrazovací rovnice 1/f = 1/a + 1/a'
- Čočky: spojky (dvojvypuklá, plankonvexní, vypuklodutá), rozptylky (dvojdutá, plankonkávní, vypukloduť)
**Téma: T7 — Geometrická optika**

## 1000057505.jpg — Mechanika (kruhový pohyb, gravitace, vrhy)
- F_o = mv²/r = mω²r, ω = 2πf = 2π/T
- F_g + F_o = F_G, výsledek směřuje k g⃗
- Tíhová síla F_G = mg
- Vrh: ↓g, ↗v₀
- v = ds/dt, a = d²s/dt²
**Téma: T8 — Mechanika hmotného bodu / kruhový pohyb / vrhy**

## 1000057506.jpg — Gravitační pole
- Newtonův grav. zákon F⃗_g = κ·m₁m₂/r² · r⃗/r, κ = 6,67·10⁻¹¹
- 1 N = 1 kg·m·s⁻²
- Intenzita K⃗ = F⃗_g/m
- Potenciál φ = −W/m, K⃗ = −grad φ
- Tíhové pole (homogenní)
**Téma: T8/T18 — Gravitační pole**

## 1000057507.jpg — Vrhy (svislý, vodorovný, šikmý)
- Svislý vzhůru: v₀ ↑, gt ↓
- Svislý dolů: v₀ ↓, gt ↓
- Vodorovný: v₀ →, gt ↓
- Šikmý: v₀ ↗, gt ↓
- Volný pád: v₀ = 0, gt ↓
**Téma: T8 — Pohyby v tíhovém poli**

## 1000057508.jpg — Hydrostatika a hydrodynamika
- Vztlaková síla F_v = V·ρ·g, F_G = V·ρ'·g (těleso)
- Plove/vznáší se/klesá: F_v vs F_G
- Rovnice kontinuity: S₁v₁ = S₂v₂
- Bernoulliho rovnice: ½ρv² + p + hρg = konst.
- Newtonův odpor: F ~ v² (Newton), F ~ v (Stokes), F ~ S
**Téma: T9 — Mechanika kapalin a plynů**

## 1000057509.jpg — Hydrostatika, povrchové napětí, kapilární jevy
- Hydrostatický tlak p_h = h·ρ·g, [p] = Pa
- Pascalův zákon F₁/S₁ = F₂/S₂
- Vztlaková síla F = F_h2 − F_h1 = S·x·ρ·g
- Pevné látky: krystalické, polykrystalické, amorfní
- Plyn-kapalina-pevná látka, fázový diagram
- Hg trojný bod ~600 Pa, T = 273,16 K
- Povrchové napětí σ = F/l, [σ] = N/m, ΔE = σ·ΔS
- Kapilární elevace/deprese
**Téma: T9 — Mechanika kapalin / T17 — Kapaliny / T22 — Skupenství**

## 1000057510.jpg — Moment setrvačnosti, otáčivý pohyb
1) Soustava 2 hmotných bodů: I = m₁r₁² + m₂r₂², I = (m₁m₂/(m₁+m₂))·r₀²
2) Moment síly M = P/ω, ω = 2πf, M⃗ = r⃗ × F⃗
- v = ω·r = 2πf·r
- Tíhová síla na svahu rozkládá se na grav. + tíhovou
**Téma: T8 — Tuhé těleso / Moment setrvačnosti**

## 1000057511.jpg — Tuhé těleso, stabilita, momenty sil
- E = ½mv² + ½Iω² + mgh
- I_0 (vzhledem k těžišti): I = I_0 + md² (Steinerova věta)
- Stabilní/labilní/indiferentní poloha tělesa
- Krychle hrana a → tělesová úhlopříčka a√3, výška Δ = a/2(√3−1)
- Práce W = m·g·a/2·(√3−1)
- Skládání rovnoběžných a různoběžných sil, M = F·r
**Téma: T8 — Tuhé těleso, momenty sil**

## 1000057512.jpg — Páka, jednoduché stroje + Povrchové napětí
- Páka: F₁·r₁ = F₂·r₂
- Kapaliny — KTL kinetická teorie látek
- ΔE = σ·ΔS, [σ] = J/m², F = σ·l, [σ] = N/m
- Fyzikální chování PL × kapalin × plynů
- Kapilární jevy: elevace, deprese
**Téma: T8 — Jednoduché stroje + T9 — Povrchové napětí**

## 1000057513.jpg — Jednoduché stroje (volné kreslení)
- Nesilkový případ rozdělení dvojice sil
- Páka rovnoramenná i nerovnoramenná
- Klín, šroub, kladka pevná/volná
**Téma: T8 — Jednoduché stroje**

## 1000057514.jpg — Deformace, Hookeův zákon, teplotní roztažnost
- Deformace = Δl/l, druhy: tah, tlak, ohyb, smyk
- σ = F/S, ε = Δl/l, σ = E·ε (Hookeův zákon, Yongův modul pružnosti)
- Délková teplotní roztažnost: (l−l₀)/l₀ = α·Δt, l = l₀(1+α·Δt)
- Objemová: 3α = β, V = V₀(1+β·Δt)
- l = φ·(R+d/2), l₂ = φ·(R−d/2), bimetal
**Téma: T10 — Pevné látky / Deformace / Roztažnost**

## 1000057515.jpg — Krystalová struktura
- PL: krystalické (monokrystaly, polykrystaly), amorfní
- Bez napětí, krystalová mřížka, různé typy: prostá, plošně centrovaná, prostorově centrovaná
- Počet atomů na buňku: prostá 1, plošně 4, prostorově 2
- Hliník Al: ρ_Al = 2700 kg/m³, A_r = 27, 4 atomy v buňce
- Výpočet objemu jedné buňky a mřížkové konstanty
**Téma: T10 — Pevné látky / krystaly**

## 1000057516.jpg — Magnetické pole, indukce, RCL obvod, transformátor
- Φ = B⃗·S⃗, [Φ] = Wb (weber)
- Faradayův zákon: u_i = −dΦ/dt (Lenzův zákon)
- Vlastní indukčnost L: Φ = L·I, W = ½LI²
- Vzájemná indukce, transformátor (1:N₁:N₂)
- Trojfázová síť — fáze 1,2,3, zapojení do hvězdy/trojúhelníku, 230 V/400 V
- Σ u_i = 0
- RCL obvod: rezistor R, kondenzátor C, cívka L, fázory u_R, u_L, u_C
- Rezonance LC: ω₀ = 1/√(LC)
**Téma: T12 — Magnetické pole / T19 — Střídavý proud / T20 — RCL obvod / Transformátor**

## 1000057517.jpg — Fyzikální veličiny, jednotky, SI
- X = {X}·[X] (číslo · jednotka)
- [F] = 1 N = 1 kg·m/s²
- [f] = Hz = 1/s
- 7 základních SI jednotek (m, kg, s, A, K, mol, cd)
- Vedlejší jednotky (°C, l, min/h, eV/keV)
**Téma: T25 — Fyzikální veličiny, jednotky, měření / Úvod do fyziky**

## 1000057518.jpg — Termodynamika ideálního plynu
1) Střední kinetická energie ½mv² 
- Ideální plyn, rozdělovací funkce, Maxwellovo rozdělení
- Boltzmannova konstanta k, ½kT na 1 stupeň volnosti
- 3·½kT (translační), 5·½kT (lin. molekula), 6·½kT = 3kT (víceatomová)
- Stavová rovnice pV = NRT, pV = nRT, pV/T = konst.
2) Tlak plynu p = F/S, atomární rychlost
- Termodynamické zákony, ΔU = Q + W
- Izoděje (izotermický, izobarický, izochorický, adiabatický)
- Účinnost η = (T₂−T₁)/T₂
**Téma: T21/T22 — Termodynamika a molekulová fyzika**

## 1000057519.jpg — Izoděje, fázové změny
- Izotermický děj T = 273,15 K, ΔU = 0
- W = ∫p dV = konst·ln(V₂/V₁)
- Q = m·c·Δt (zahřívání)
- Skupenské přeměny: tání 0°C → 0°C, varu 100°C → 100°C
- L (skupenské teplo) — Q = L·m
**Téma: T21/T22 — Termodynamika, skupenské přeměny**

## 1000057520.jpg — Měření, chyby
- Druhy chyb: systematické (měřidlem), hrubé, náhodné (opakování)
- Tabulka X | xᵢ−x̄ | (xᵢ−x̄)²
- Aritmetický průměr x̄ = (1/n)·Σxᵢ
- Σ(xᵢ−x̄) = 0
- Směrodatná odchylka 1 měření: s₁ = √(Σ(xᵢ−x̄)²/(n−1))
- Směrodatná odchylka průměru: s = s₁/√n
- Studentovo rozdělení, X = x̄ ± s
**Téma: T25 — Fyzikální měření a chyby**
